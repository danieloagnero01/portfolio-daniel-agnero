Application web

Automatisation des rondes de supervision

Cette application web a été conçue pour automatiser et faciliter la gestion des rondes de supervision dans un datacenter.

Objectif du projet

L'objectif est de remplacer une partie du suivi manuel des rondes par une solution numérique permettant d'enregistrer, consulter et suivre les informations relatives aux équipements supervisés.

Fonctionnalités

  • Gestion des utilisateurs
  • Enregistrement des rondes
  • Gestion des équipements
  • Suivi des observations
  • Gestion des rapports
  • Tableau de bord
  • Export des données

Technologies utilisées

Laravel PHP MySQL HTML CSS JavaScript
